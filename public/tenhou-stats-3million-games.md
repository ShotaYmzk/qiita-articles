## はじめに

天鳳(オンライン麻雀)の鳳凰卓の牌譜を、2009年から2024年まで全部集計しました。

- 対局数: **3,038,665対局**
- 局数: **28,899,232局**(1対局あたり平均9.5局)
- 和了: 24,446,146回
- 対象: 四人麻雀の鳳凰卓(参加者は七段以上)

「役満は何局に1回出るのか」「先制立直と追っかけ立直で和了率はどれだけ違うのか」「最初に切る牌は何が多いのか」といった、麻雀を打つ人なら気になりそうな数字を、まとめて出しました。

:::note info
プレイヤー個人の名前や成績は一切使わず、全体の傾向だけを集計しています。
:::

## データと集計の方法

天鳳が公開している牌譜(XML形式)を、Pythonで1局ずつ読んで、年ごとにカウンターを作りました。

- 牌譜は全部で約3,038,665ファイル(約32GB)
- 1ファイルずつ正規表現で読む(XMLパーサは使わない)。並列は30プロセス
- 全ファイルの処理は **3分42秒** で、読み込みエラーは0件
- 計算はCPU(Ryzen 9 7950X3D、32スレッド)だけです。GPUを使う場面はありませんでした

牌譜には、全員の配牌、ツモ、打牌、鳴き、立直、和了(役・点数・ドラ)がすべて入っているので、「どんな局面で何が起きたか」を、後から好きなように数えられます。

対局の種類は、半荘戦が76.4%、東風戦が23.4%でした(残りの約0.2%は別の種別の卓)。

### 数え方(この記事で使う定義)

| 指標 | 数え方 |
|---|---|
| 和了率 | 1人1局あたり、和了した割合 |
| 放銃率 | 1人1局あたり、ロンされた割合 |
| 立直率 | 1人1局あたり、立直が成立した割合(宣言牌がロンされて不成立の場合は含めない) |
| 副露率 | 1人1局あたり、チー・ポン・大明槓・加槓のどれかをした割合(暗槓だけは含めない) |

## まず、全体の数字

| 指標 | 値 |
|---|---:|
| 和了率 | **21.15%** |
| 放銃率 | **12.52%** |
| 立直率 | 16.66% |
| 副露率 | 34.43% |
| 流局(局あたり) | 15.98% |

和了のうち、**ツモ和了が40.1%、ロン和了が59.9%** です。立直で和了したのが39.4%、副露して和了したのが47.0%、ダマテンで和了したのが13.6%でした。

和了1回の平均点は、**立直なら7,457点、副露なら4,166点、ダマなら5,542点**。親の和了は平均7,538点、子の和了は平均4,930点です。

和了の等級は次のとおりでした。

| 等級 | 割合 |
|---|---:|
| 満貫未満 | 75.9% |
| 満貫 | 16.2% |
| 跳満 | 6.8% |
| 倍満 | 0.93% |
| 三倍満 | 0.03% |
| 役満(数え役満を含む) | 0.09% |

## 役満は、何局に1回出るのか

役満の和了は、16年間で **20,848回**。**1,386局に1回、146対局に1回** の割合です。ツモ和了が12,537回(60.1%)、ロン和了が8,311回で、親が4,921回(23.6%)でした。

![役満の出現回数](https://raw.githubusercontent.com/ShotaYmzk/mahjong-ai-qiita-images/main/tenhou_02_yakuman.png)

- いちばん多いのは**四暗刻**(8,023回、約3,600局に1回)。次いで**国士無双**(4,822回)、**大三元**(4,241回)
- **天和は87回**(約332,000局に1回)。これは天和の確率の理論値(約33万分の1)とほぼ一致しています
- **地和は246回**。非親は3人いるぶん、天和より出やすい結果です
- **純正九蓮宝燈は16年で7回**、**四槓子は2回**
- ダブル役満(四暗刻単騎・国士無双13面待ち・大四喜・純正九蓮宝燈、または複数の役満の重なり)は1,389回
- 責任払いが発生した役満は398回(大三元・大四喜・四槓子のどれか)
- 数え役満(13翻以上)は、約1,119回(役満の等級の和了21,967回から、役満の役を引いた数)

年ごとの役満は、1万局あたり6.85回(2012年)〜7.87回(2020年)の範囲で、大きなトレンドはありません。

## 16年間で、打ち方はどう変わったか

![年別の推移](https://raw.githubusercontent.com/ShotaYmzk/mahjong-ai-qiita-images/main/tenhou_01_trend_by_year.png)

- **立直率は増えました**。2012年の15.18%から、2024年は17.75%
- **副露率は減りました**。2012年の37.22%から、2024年は32.98%
- 和了率は21.1〜21.5%、放銃率は12.4〜13.1%で、16年間ほとんど動いていません
- 和了1回の平均点は、2012年の5,429点から、2024年は5,761点に上がっています

「立直が増えて、鳴きが減った。和了率は変わらず、打点が上がった」という流れです。

## 立直の統計

### 先制立直と追っかけ立直

立直が成立した局を、「その局で最初に立直した人(先制)」と「他に立直が先にあった人(追っかけ)」に分けて、結果を数えました。

![先制と追っかけの結果](https://raw.githubusercontent.com/ShotaYmzk/mahjong-ai-qiita-images/main/tenhou_04_riichi.png)

| 立直した局の結果 | 先制立直 | 追っかけ立直 |
|---|---:|---:|
| 和了 | **52.0%** | **39.5%** |
| 放銃 | 10.3% | 15.4% |
| ツモられ | 11.9% | 21.6% |
| 他家のロン | 7.9% | 10.6% |
| 流局 | 17.9% | 12.8% |

**先制立直は2回に1回あがり、追っかけは10回に4回弱**です。追っかけは、放銃が1.5倍、ツモられが1.8倍に増えています(立直が成立した局、1,926万回の集計)。

立直を打った人全体では、**和了率は49.95%、放銃率は11.17%** でした(「立直した局のうち」の割合)。

### 立直は何巡目が多いか

立直を宣言した巡目(自分の何打目か)は、**8巡目が12.6%で最多**、次いで9巡目、7巡目でした。3巡目までの立直は、合計でも3.4%しかありません。

### 一発と裏ドラ

立直で和了した局のうち、**一発が付いたのは18.7%**、**裏ドラが1枚以上乗ったのは31.6%** でした。裏ドラは平均0.41枚です。

### 立直宣言牌は何が多いか

![立直宣言牌](https://raw.githubusercontent.com/ShotaYmzk/mahjong-ai-qiita-images/main/tenhou_06_riichi_tile.png)

どのスートでも、**5が最多(4.1%)**、次いで3・7(3.7〜3.8%)、4・6(3.5%)でした。端牌(1・9)は2.4%、字牌は1.4〜1.5%と少なめです。宣言牌がツモ切りだったのは、2.95%だけでした(ほとんどの立直は、手牌から切って聴牌しています)。

## 最初に切る牌は何か

各プレイヤーの第一打(最初の打牌)を、約1億1,480万人局ぶん数えました。

![第一打](https://raw.githubusercontent.com/ShotaYmzk/mahjong-ai-qiita-images/main/tenhou_05_first_discard.png)

- 字牌が **57.0%**、老頭牌(1・9)が35.2%で、**合わせて92.2%が字牌か老頭牌**
- 字牌では、**西(13.5%)と北(13.4%)が多く**、東は8.9%、南は10.0%
- 三元牌(白・發・中)は、それぞれ3.6〜3.8%と少なめ(役牌になるので、残す人が多い)
- 中張牌(2〜8)が第一打になるのは、全体のわずか **7.8%**
- 第一打がツモ切りだったのは7.4%

第一打を、自風・場風・客風に分けると次のとおりです。

| 第一打の種類 | 割合 |
|---|---:|
| 客風(自風でも場風でもない風牌) | 37.4% |
| 老頭牌(1・9) | 35.2% |
| 三元牌 | 11.2% |
| 中張牌 | 7.8% |
| 場風(自風と別) | 5.3% |
| 自風 | 2.8% |
| 連風(自風かつ場風) | 0.28% |

自風・場風の牌は、役牌なので残される(第一打にされにくい)ことがはっきり出ています。

## 配牌の統計

配牌13枚のシャンテン数を、全体の20分の1(約578万手)を抜き出して計算しました。

![配牌のシャンテン数](https://raw.githubusercontent.com/ShotaYmzk/mahjong-ai-qiita-images/main/tenhou_07_haipai_shanten.png)

- 平均は **3.58向聴**。**4向聴が39.9%、3向聴が36.2%** で、この2つで76%
- **配牌が1向聴以下なのは、わずか0.6%**。配牌で聴牌しているのは約1万2,600手に1回
- 七対子が通常手より近い配牌は **17.0%**、国士無双が最短の配牌は1.1%
- 赤ドラが配牌に **1枚入るのは23.8%、2枚は2.3%、3枚は0.07%**(0枚は73.8%)
- ドラが配牌に **2枚以上入るのは4.6%**

九種九牌については、「最初のツモで、幺九牌が9種類以上ある」機会が36万2,492回あり、そのうち **83.0%** で九種九牌の流局を選んでいました。

## 和了は何巡目が多いか

![和了巡目](https://raw.githubusercontent.com/ShotaYmzk/mahjong-ai-qiita-images/main/tenhou_11_win_junme.png)

和了した人の、何打目で和了したかの中央値は **11打目**(ツモもロンも)。最頻値は、ツモ和了が11打目、ロン和了が10打目でした。

## 段位が上がると、何が違うのか

七段・八段・九段・十段・天鳳位の成績を比べました(各段位は牌譜に記録された対局時点のもの)。

![段位別](https://raw.githubusercontent.com/ShotaYmzk/mahjong-ai-qiita-images/main/tenhou_08_by_dan.png)

| 段位 | 和了率 | 放銃率 | 立直率 | 副露率 | 平均順位 |
|---|---:|---:|---:|---:|---:|
| 七段 | 21.08% | 12.73% | 16.64% | 34.39% | 2.511 |
| 八段 | 21.24% | 12.34% | 16.70% | 34.53% | 2.489 |
| 九段 | 21.28% | 11.91% | 16.65% | 34.42% | 2.470 |
| 十段 | 21.23% | 11.52% | 16.78% | 33.53% | 2.454 |
| 天鳳位 | 21.15% | 11.62% | 16.52% | 34.04% | 2.447 |

**段位が上がっても、和了率はほとんど変わりません。差が出るのは放銃率です。** 七段の12.73%に対して、十段は11.52%。立直率や副露率にも、ほとんど差がありません。

:::note warn
天鳳位の標本は約17万人局(約1.6万対局)と少なめです。また、図の縦軸は0から始めていません(差を見やすくするため)。段位は対局時点のものですが、強い人ほど段位が高いので、段位別の成績は「上位の人はこう打つ」ことの大まかな目安です。
:::

## 流局と、途中流局

荒牌平局(山を取り切った流局)のときの聴牌人数は、 **2人が42.3%、1人が39.2%、3人が14.5%** で、0人と4人はどちらも2.0%でした。

![流局](https://raw.githubusercontent.com/ShotaYmzk/mahjong-ai-qiita-images/main/tenhou_10_draws.png)

途中流局(1万局あたり)は、九種九牌が104回(約1%)、四風連打が6.4回、流し満貫が1.7回、四家立直が0.93回、三家和が0.32回、四開槓が0.13回でした。ダブロンは163,833回で、ロン和了の局の約1.1%です。

## ほかの数字

- **親の和了率は23.3%、子の和了率は20.4%**。親の連荘率(次の局も同じ親)は33.4%
- 鳴き(16年の合計): ポン3,323万回、チー2,497万回、暗槓128万回、加槓90万回、**大明槓19万回**
- **起家別の平均順位**(東家が最初の親): 起家2.499、南家2.503、西家2.510、北家2.489と、どの席もほぼ2.50

## まとめ

- 鳳凰卓の300万対局・2,890万局を、3分42秒で集計できた
- 和了率は21.15%、放銃率は12.52%。16年間ほとんど変わっていない
- 役満は1,386局に1回(天和は約33万局に1回で、理論値どおり)
- 立直は増え、鳴きは減った。平均打点は上がった
- 先制立直は52.0%あがるが、追っかけ立直は39.5%
- 第一打の92%は字牌か老頭牌。中張牌は7.8%だけ
- 配牌の平均は3.58向聴で、1向聴以下はわずか0.6%
- 段位が上がると、和了率ではなく放銃率に差が出る

## 注意

- 集計対象は、天鳳の鳳凰卓(参加者は七段以上)の牌譜です。ほかの卓(一般卓・上級卓・特上卓)には当てはまりません
- 数え方は、この記事の「数え方」の表のとおりです。ほかのサイトの統計とは、定義が違う場合があります(特に立直率は、立直が成立したものだけを数えています)
- 配牌のシャンテン数は、全体の20分の1(約578万手)を抜き出した値です。ほかは全数を集計しています
- 天鳳位の標本は少なめです。段位別の差は、「強いほどこう」と断定せず、傾向として読んでください
